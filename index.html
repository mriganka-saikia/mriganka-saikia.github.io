Technical summary

Every project here follows the same path: a request leaves the browser, passes through an API, lands in a database, and sometimes asks a model for its opinion. This is that path, layer by layer.

  1. Interface

    ReactViteTailwind CSSChakra UI

    Component-based screens for live train delays, bookings, chat, and inventory.

  2. Services

    Node.jsExpressFastAPISocket.IOJWT auth

    REST APIs with token login and role-based access, plus sockets where chat and live updates matter.

  3. Data

    MongoDBPostgreSQLSQLRedisSupabase

    Documents for fast-changing records. Relational rules where bookings must never overlap and credits must never be spent twice.

  4. Intelligence

    PythonXGBoostSHAPscikit-learnGemini

    Delay forecasts that come with a confidence range and a reason, and AI-written descriptions for listings.

  5. Delivery

    DockerDocker ComposeRazorpay

    Containerised services that start with one command, and online payments for paid sessions.
